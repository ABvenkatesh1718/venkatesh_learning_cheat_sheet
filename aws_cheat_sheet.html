☁️ AWS EC2 & Terminal Reference Guide

1. Connecting via Local PowerShell

Step 1 Move to .pem Key Location

Navigate your local terminal to the folder containing your downloaded AWS private key file.

cd C:\Users\YourUsername\Downloads
Step 2 Lock Permissions (Windows Only)
icacls .\my-spring-key.pem /inheritance:r /grant:r "$($env:USERNAME):(R)"
Step 3 Establish Cloud SSH Connection
ssh -i .\my-spring-key.pem ubuntu@YOUR_EC2_PUBLIC_IP
⚠️ First connection prompt? Type yes and hit Enter.

2. Initial Server Environments

Refresh Ubuntu OS Packages
sudo apt update -y
Download & Install Java 25 (JRE Headless)
sudo apt install openjdk-25-jre-headless -y
Download & Install Git Engine
sudo apt install git -y
Verify Java Installation Version
java -version

3. Modern Core Engine: Docker Deployment

Quick-Install Docker Suite
sudo apt install docker.io -y
Verify Docker Installation
docker --version
Run Container 24/7 (Detached Self-Healing Engine)
docker run -d -p 8080:8080 --restart always --name my-spring-api your-image-name

4. Process & Service Management

Check what is running on Port 8080
sudo lsof -i :8080
Stop a background systemd application
sudo systemctl stop springbootapp
Kill all running Java instances instantly
sudo killall java
