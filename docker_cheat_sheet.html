Docker Commands Cheat Sheet

Useful for sharing or running projects smoothly without dependency worries.
💡 ENVIRONMENT PRESETS FOR EXAMPLES: Assuming local environment has an existing image named "mysql" or "python-app", and a running container instance named "python-app".
1) Check Docker Installed Version
Command Template docker --version
2) Check Docker System Information
Command Template docker info
3) View Help Guidelines
Command Templates docker --help
docker logs --help
docker pull --help
4) Search Registry For Specific Images
Command Template docker search <image_name>
Example Execution docker search mysql
5) Pull Image from Central Registry to Local
Command Template docker pull <image_name>
Example Execution docker pull mysql
6) Check Pulled Local Docker Images
Command Template docker image
7) Delete / Remove Local Image
Command Template docker rmi <image_name>
Example Execution docker rmi mysql
8) Run Image (Start a Container Interactively)
Command Template docker run <image_name>
Example Execution docker run mysql
9) Run Image in Detached Mode (Background)
Command Template docker run -d <image_name>
Example Execution docker run -d mysql
10) Check Actively Running Containers
Command Template docker container ls
11) Check All Existing Containers (Running + Stopped)
Command Template docker container ls -a
12) Expose Port Mapping (Host Network to Container Network)
Command Template docker run -p hosting-port:network-port <image_name>
Example Execution docker run -p 8080:8080 java-app
13) Run Container Assigned with Specific Name
Command Template docker run --name <custom_container_name> <image_name>
Example Execution docker run --name "python-app" python-app
14) Review Background Detached Container Logs
Command Template docker logs <container_name>
Example Execution docker logs mysql
15) Live Stream/Monitor Logs Follow Mode
Command Template docker logs -f <container_id_or_name>
Example Execution docker logs -f "python-app"
16) Start a Existing Stopped Container
Command Template docker start <container_id_or_name>
Example Execution docker start "python-app"
17) Stop / Terminate Running Container
Graceful Stop Template (Allows graceful shutdown cleanup time) docker stop <container_id_or_name>
Immediate Kill Template (Forces direct application termination) docker kill <container_id_or_name>
Example Executions docker stop "python-app"
docker kill "python-app"
18) Restart Container Process
Command Template docker restart <container_id_or_name>
Example Execution docker restart "python-app"
19) Remove / Delete Stopped Container Instance
Command Template docker rm <container_id_or_name>
Example Execution docker rm "python-app"
20) Build Custom Docker Image via Dockerfile
Command Template docker build -t <image_name>:<version> .
Example Execution docker build -t "java-sample-app":1.0.0 .
21) Clean / Prune Unused Containers and Images
Command Templates docker container prune
docker image prune
22) Remove Unused System-Level Resources Completely
Command Template docker system prune
23) Inspect General Engine Disk Usage Data
Command Template docker system df
24) View Execution History Layers of an Image
Command Template docker image history <image_name>
Example Execution docker image history mysql
25) Monitor CPU & Memory Utilization Statistics
Command Template docker stats <container_id_or_name>
Example Execution docker stats "python-app"
26) Run Container with Specific Resource Limitations
Command Template (-m: Max Memory Allocation limit | --cpu-quota: Maximum CPU quota limit where 100,000 is 100% core) docker container run -m 500m --cpu-quota=50000 <image_name>
27) Access Shell (Bash Terminal) of Active Container
Command Template docker exec -it <container_name_or_id> bash
Example Execution docker exec -it mysql bash
28) Show Detailed Breakdown Disk Space Usage
Command Template docker system df
